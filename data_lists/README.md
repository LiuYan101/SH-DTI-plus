# Subject identifiers

- `mgh_hcp.txt`: MGH_1001 through MGH_1032 (32 subjects).
- `chcp.txt`: the 20 CHCP subjects specified for this study.

These files identify the cohorts. They do not assign training, validation or test splits. Select the appropriate subjects in a case manifest and keep all patches from one subject in the same split. Source images and model weights are not included.
